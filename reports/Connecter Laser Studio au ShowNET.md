# Relier Laser Studio au ShowNET légalement

Il existe aujourd'hui, pour un développeur open-source solo sur macOS et à petit budget, **un chemin légitime qui fonctionne tout de suite et sans frais logiciels : faire émettre à Laser Studio son flux PONK vers TouchDesigner en licence Non-Commercial (gratuite), dont le « Laser Device CHOP » pilote nativement le ShowNET par Ethernet, sans licence ni matériel supplémentaire** ([Derivative : Laser Device CHOP](https://docs.derivative.ca/Laser_Device_CHOP) ; [Laserworld : TouchDesigner + ShowNET](https://www.laserworld.com/en/newslist/5805-touchdesigner-supports-direct-output-to-shownet-laser-mainboards.html)). Un seul inconnu décisif subsiste et doit être levé par un test pratique : le plugin PONK (un Custom Operator C++ de MadMapper) se charge-t-il réellement sous la licence Non-Commercial ? La source officielle la plus autoritaire dit oui depuis 2019, mais la doc de Derivative se contredit encore et aucun retour d'utilisateur ne le confirme pour ce plugin précis ([Derivative : What's New in 099 2019.10000](https://docs.derivative.ca/What's_New_in_099_2019.10000)). En parallèle, le SDK officiel du ShowNET est, sur le papier, ouvert à un « projet logiciel disponible publiquement » comme Laser Studio — mais il est verrouillé par une NDA exigeant une « adresse professionnelle légale », par le silence de Laserworld, et par un coût non publié ; et le ShowNET offre aussi une voie 100 % gratuite et sans NDA (fichiers ILDA sur carte SD déclenchés en Art-Net), à condition de mettre à jour un firmware de 2016. Aucun projet open-source ni aucun contournement de rétro-ingénierie ne pilote le ShowNET en direct, et aucun n'est recommandé.

## Le SDK est ouvert à un projet public, mais barré par la NDA et une « adresse professionnelle »

La page officielle du SDK tranche la question de l'éligibilité sur un axe **public contre privé**, pas entreprise contre individu. Elle écrit noir sur blanc : **« If you have a publicly available software project, this is exactly for you »**, tout en refusant les projets privés — **« We unfortunately cannot provide further supprot [sic] for private projects »** — et en orientant les hobbyistes vers les intégrations toutes faites comme TouchDesigner ([Laserworld ShowNET API/SDK](https://www.laserworld.com/en/software/more-shownet-compatible-software/shownet-api-sdk.html)). Un projet open-source publié sur GitHub est l'exact opposé d'un « projet privé » dans leur vocabulaire : Laser Studio tombe donc, sur le texte même de la page, dans l'audience visée. Le SDK est livré sous forme de bibliothèque binaire pour Windows (x86/x64) et **macOS Intel + Apple Silicon/M1** (plus un build Linux « expérimental ») — une couverture qui correspond exactement à la cible de Laser Studio ([annonce de lancement 2022](https://laserworld.com/en/newslist/5625-shownet-api-sdk-available.html) ; [PLSN](https://plsn.com/?p=352037)).

Le vrai obstacle n'est pas le type de projet mais la **NDA** : « we make a little NDA with each integration partner » pour que **les clés, créées individuellement par partenaire, restent dans le projet**, et la demande exige **« the legal business address for the NDA »** ([Laserworld SDK](https://www.laserworld.com/en/software/more-shownet-compatible-software/shownet-api-sdk.html)). C'est le point le plus incertain de tout le dossier : **aucune source publique ne dit si une adresse personnelle (sans entreprise) est acceptée**. L'expression « legal business address » pointe vers une entité enregistrée. Pour un particulier belge, la structure la moins chère qui produirait à coup sûr cette adresse est l'**entreprise individuelle / eenmanszaak** : pas de capital minimum, pas de notaire, le domicile peut servir de siège social, pour environ **105,50 € d'inscription à la BCE + ~70 € de frais** (certaines démarches étant gratuites en self-service), bouclée en une semaine ([Deel](https://www.deel.com/blog/sole-proprietorship-belgium/) ; [Accountable.eu](https://www.accountable.eu/?p=5423) ; [business.belgium.be](https://business.belgium.be/4)). Former une société (SRL/BV, ~3 280 € + notaire) est inutile ici. Mais avant de dépenser, il faut **demander directement à Laserworld s'ils acceptent une adresse d'indépendant, voire une adresse privée**.

Bonne nouvelle sur le plan open-source : **signer la NDA et publier Laser Studio en open-source sont compatibles**. La NDA, telle que décrite, protège **les clés et le binaire du SDK**, pas le code source de l'application. Garder la bibliothèque et les clés hors du dépôt Git public derrière la feature Cargo `shownet` (désactivée par défaut) et publier le reste sous MIT/GPL est l'arrangement « open-core » standard ([terms.law, guide NDA + OSS](https://terms.law/NDA/scenarios/software-dev/open-source-nda.html) ; précédent Realtek/MediaTek — [MediaTek Genio](https://genio-community.mediatek.com/t/what-license-model-is-required-to-access-the-aosp-sdk/364)). Deux précautions à vérifier sur le texte réel de la NDA une fois reçu : qu'elle n'impose pas la confidentialité sur le code publié de l'application (demander un *carve-out* explicite), et que la combinaison binaire reste propre côté licence (MIT évite toute question de copyleft). Enfin, **aucun tarif n'est publié** sur aucune des trois sources consultées : le SDK est présumé gratuit (l'intérêt commercial de Laserworld étant de vendre du matériel ShowNET), mais **ce n'est confirmé nulle part** et doit être demandé par écrit ([Laserworld SDK](https://www.laserworld.com/en/software/more-shownet-compatible-software/shownet-api-sdk.html) ; [PLSN](https://plsn.com/?p=352037)).

Côté pratique de la demande, le formulaire d'inscription est **cassé** : `laser-interface.com/en/sdk` renvoie un HTTP 301 vers une URL malformée qui ne résout pas, confirmé en octobre 2026 ([redirection vérifiée] ; écho du lien mort par [PLSN](https://plsn.com/?p=352037)). Le seul canal vivant est le contact humain : la page dit « reach out to Norbert » — c'est-à-dire **Norbert Stangl, directeur Sales/Marketing** de Laserworld (Suisse) AG ([LaserFocusWorld](https://laserfocusworld.com/directory/laser-sources/laser-diodes/company/14048090/laserworld-switzerland-ag) ; [essai de N. Stangl sur l'ouverture du SDK](https://www.laserworld.com/en/newslist/6106-fundamental-evolution-in-the-show-laser-industry.html)). Qu'un contact marketing traite la demande explique probablement le silence déjà constaté. Le canal officiel le plus fiable est le **siège suisse : Laserworld AG, Kreuzlingerstrasse 5, CH-8574 Lengwil, tél. +41 71 677 80 80** ([mentions légales Laserworld](https://www.laserworld.com/en/imprint.html)) ; joindre Stangl via LinkedIn ou un salon (Prolight+Sound) est une piste. Il faut employer **leurs mots qualifiants** (« publicly available software project », « commercial integration partner »), fournir l'adresse d'emblée, et signaler le lien d'inscription cassé — un signal de vrai intégrateur.

## Des micro-éditeurs indépendants ont déjà obtenu le SDK — la taille n'est pas le critère

La preuve que le SDK n'est pas réservé aux grandes entreprises est directe. La page officielle « ShowNET compatible » liste **huit** applications à sortie ShowNET directe : Showcontroller, Showeditor, MadMapper/MadLaser, TouchDesigner, ILD Render, Millumin, **Modulaser** et **CloudLase Studio** ([Laserworld ShowNET compatible](https://laserworld.com/en/shownet-compatible.html)). Les deux premières sont les logiciels maison de Laserworld (non pertinents). Parmi les intégrateurs tiers, les deux plus récents sont des **micro-entités** : **Modulaser = RS Product Studio B.V.**, une société néerlandaise à l'échelle d'une personne (2 abonnés GitHub, aucun salarié nommé, un seul produit, licences one-time à l'échelle indie : Standard 179 €, Pro 499 €) ([modulaser.app](https://modulaser.app/) ; [github.com/ModulaserApp](https://github.com/ModulaserApp)) ; et **CloudLase Studio = BX Precision Engineering, « Made in Australia »**, un nom commercial sans trace de registre d'entreprise retrouvée, aux tarifs indie (Pro 59 $ one-time, gratuit pour étudiants) ([cloudlase.studio](https://cloudlase.studio)). Les autres tiers sont de petites structures établies : Derivative (TouchDesigner, Toronto), GarageCube + 1024 architecture (MadMapper, équipe dev à Bruxelles) et Anomes SARL (Millumin, France) ([madmapper.com/aboutus](https://madmapper.com/aboutus) ; [Millumin / Laserworld](https://laserworld.com/en/shownet-compatible/millumin)).

La leçon est que **le verrou est la forme juridique/commerciale, pas l'échelle** : une B.V. unipersonnelle et un apparent indépendant australien ont tous deux passé la barre. Un développeur solo qui enregistre une structure commerciale minimale avec une adresse professionnelle satisfait, selon toute vraisemblance, le seuil affiché. Mieux : **Modulaser est le jumeau architectural de Laser Studio** — il open-source (MIT) ses composants *génériques* (le codec `ponk-protocol` et les drivers `laser-dac-rs` en Rust) tout en gardant la partie ShowNET/SDK fermée hors du dépôt public ([github.com/ModulaserApp/laser-dac-rs](https://github.com/ModulaserApp/laser-dac-rs)). C'est exactement le découpage que Laser Studio planifie déjà (feature `shownet`, SDK hors Git). Cela dit, **aucun intégrateur n'a publié de récit de première main de son onboarding** (délais, texte de la NDA, coût), et aucune histoire de réussite d'un pur particulier sans structure n'a été trouvée ; le développeur indépendant le plus connu, Seb Lee-Delisle (Liberation), a au contraire **refusé délibérément** de bâtir sur ce SDK à cause de sa dépendance « manufacturer-controlled » révocable ([forum Liberation Laser](https://forum.liberationlaser.com/t/are-laserworld-ds-1000-mk4-s-supported/2126)).

## TouchDesigner Non-Commercial : le meilleur pont gratuit, à un test près

Puisque le flux de points en direct du ShowNET est chiffré et fermé, **aucune application open-source ne peut lui parler directement** — il faut passer par un hôte licencié. Le pont le plus avantageux est **TouchDesigner en licence Non-Commercial (gratuite, sans expiration depuis 2021)**, dont le **Laser Device CHOP est un opérateur natif** qui « sends laser points to EtherDream, Helios, and ShowNET devices » en auto-détectant les cartes ShowNET sur le LAN, **« eliminates the need for additional licenses or extra hardware components »**, jusqu'à 40 cartes par réseau ([Derivative : Laser Device CHOP](https://docs.derivative.ca/Laser_Device_CHOP) ; [Laserworld : TouchDesigner + ShowNET](https://www.laserworld.com/en/newslist/5805-touchdesigner-supports-direct-output-to-shownet-laser-mainboards.html) ; [Derivative : Licensing](https://derivative.ca/UserGuide/Licensing)). La chaîne cible est : **Laser Studio (émet du PONK) → plugin PonkReceiver dans TouchDesigner → Laser CHOP → Laser Device CHOP (ShowNET) → projecteur**. Laser Studio émet déjà du PONK, donc ce chemin réutilise la brique existante : le code du projet (`studio/src/ponk.rs`) envoie en unicast vers **`127.0.0.1:5583`** (le port PONK conventionnel de MadMapper) sous le nom d'opérateur **« Laser Studio »** au format `XyF32RgbU8` — ces valeurs doivent correspondre à ce qu'attend le PonkReceiver.

**La question décisive est de savoir si le plugin PONK charge sous Non-Commercial.** Le plugin PONK (« Path Over Network », Apache-2.0, développé et financé par MadMapper, gratuit sur GitHub pour macOS et Windows) est distribué comme **Custom Operator C++** — un binaire à déposer dans le dossier Plugins de TouchDesigner ([Derivative : Ponk for TouchDesigner](https://derivative.ca/community-post/ponk-path-over-network-touchdesigner/74438) ; [github.com/madmappersoftware/Ponk](https://github.com/madmappersoftware/Ponk)). La source officielle la plus autoritaire est favorable : depuis le build 2019.10000, **« C++ operators now run on all license types including Non-Commercial »**, et les Custom Operators ont été introduits précisément en levant ces limites ([Derivative : What's New in 099 2019.10000](https://docs.derivative.ca/What's_New_in_099_2019.10000)). Une page produit de Derivative **se contredit** pourtant en listant encore « C++ OPs » parmi les exclusions Non-Commercial ([Derivative : TouchDesigner Products](https://docs.derivative.ca/TouchDesigner_Products)), alors qu'une autre version de la page d'exclusions ne les mentionne plus ([Derivative : Non-Commercial](https://derivative.ca/UserGuide/TouchDesigner_Non-Commercial)). La mention résiduelle est très probablement un vestige d'avant 2019, mais **aucun retour d'utilisateur ne confirme ce plugin PONK précis sous Non-Commercial : un test pratique reste indispensable** (installer le plugin dans une install Non-Commercial et vérifier qu'il apparaît dans le menu OP Create sans erreur de licence). Autres inconnues à lever en lisant le dépôt : l'emplacement d'install exact, le nom de l'opérateur receiver, le port/mode UDP attendu (multicast par défaut vs unicast loopback) et l'existence d'un binaire précompilé dans les Releases.

Deux réserves subsistent même si le plugin charge. D'abord, la licence Non-Commercial est **gratuite et légale uniquement pour un usage non rémunéré** (perso, apprentissage, shows gratuits) ; **un spectacle payé exige une licence Commercial/Pro** (600 $) — le fait que Laser Studio soit open-source ne change rien, c'est l'usage que fait l'opérateur de TouchDesigner qui détermine le tier ([Derivative : Licensing](https://derivative.ca/UserGuide/Licensing)). Ensuite, Laserworld signale une **« limited output resolution if no license is purchased »** en Non-Commercial ; le plafond raster connu (1280×1280) concerne la vidéo, pas le vectoriel laser, mais **aucune valeur chiffrée** du plafond laser n'a été trouvée — à mesurer sur du contenu réel ([Laserworld : TouchDesigner](https://www.laserworld.com/en/shownet-compatible/touchdesigner) ; [Derivative : Non-Commercial](https://derivative.ca/UserGuide/TouchDesigner_Non-Commercial)). Si le plugin PONK refusait de charger, un **filet de secours 100 % natif** existe : faire émettre à Laser Studio un flux de points en **OSC/UDP** reçu par un OSC CHOP / UDP In DAT natif, reconstruire les polylignes, puis alimenter le Laser CHOP — plus de dev côté Laser Studio, mais aucun opérateur C++ en jeu.

Les deux autres ponts PONK sont moins bons pour un usage réel gratuit. **MadMapper** (le chemin qui marche déjà pour le projet) n'est gratuit qu'en démo, avec un **blackout laser toutes les 120 s** et sans sauvegarde ; l'usage réel coûte 519 € perpétuel ou 49 €/mois ([MadMapper madbundle](https://www.madmapper.com/madbundle)). **Modulaser** a un essai gratuit sans expiration où le ShowNET fonctionne, mais **plafonné à 15 min par session et 2 lasers**, et son entrée se fait en **NDI/Syphon (vidéo raster)**, pas en PONK vectoriel — un aller-retour raster dégradant pour du laser ([modulaser.app](https://modulaser.app)). Le vectoriel sans perte passe donc par PONK → TouchDesigner.

## La voie gratuite du boîtier lui-même : fichiers SD déclenchés en Art-Net, firmware à jour

Le ShowNET offre une voie **entièrement gratuite, sans NDA, sans MadMapper et sans matériel supplémentaire** : stocker des fichiers ILDA sur sa carte microSD interne et les **sélectionner/moduler en direct par Art-Net sur l'Ethernet du boîtier**. La sélection de motif est triviale — en **Professional Mode**, le **canal DMX 2 choisit le fichier par son numéro** (1 = `001.ild`, 2 = `002.ild`… 255 max ; 0 = blackout, `000.ild` ne doit pas exister) et peut changer à chaque trame Art-Net (sur le beat, en séquence, en timecode), tandis que d'autres canaux règlent en temps réel intensité (ch1), vitesse (ch3), rotation (ch8), taille (ch10/11), couleur (ch13 + RGB custom ch14-16), strobe (ch17), scan speed (ch18) et zones de sécurité (ch19/20) ([Laserworld DMX Table — Professional Mode, firmware 2021010602](https://www.laserworld.com/images/al_gfx/online-manual/DMX-tables/DMX-Table-ShowNET-Laser-Mainboard_-_professional_Mode.pdf) ; [Laserworld : ShowNET as mainboard](https://www.laserworld.com/en/technical-explanations-overview/shownet-as-laser-mainboard.html)). Point crucial côté matériel : **l'Art-Net voyage sur le port Ethernet intégré du ShowNET (nœud Art-Net embarqué), sans adaptateur** — seul le DMX512 physique sur XLR nécessite l'adaptateur DMX payant ([Laserworld : ShowNET PRO](https://www.laserworld.com/en/laser-software/laserworld-shownet-pro-interface.html) ; [FAQ adaptateur DMX](https://www.laserworld.com/en/shownet-faq/5894-how-can-i-use-dmx-to-trigger-the-external-shownet-interface.html)). Cette voie correspond exactement à ce que Laser Studio implémente déjà (`sdbank.rs`/T-302 exporte `001.ild`–`229.ild` en format 5 ; `--shownet-artnet`/T-301 choisit le fichier par Art-Net). La recherche confirme que le design est correct et fournit la cartographie de canaux de référence.

Le **prérequis réel est le firmware**. Les fonctions avancées (profils DMX / Professional Mode, zones de sécurité, color balancing, sélecteur RGB) ont été **ajoutées par du firmware plus récent** ; la table Professional Mode publiée porte le firmware **2021010602** (2021), alors que l'unité de l'utilisateur tourne **2016050502** (2016), qui précède presque certainement le Professional Mode ([Laserworld : ShowNET as mainboard](https://www.laserworld.com/en/technical-explanations-overview/shownet-as-laser-mainboard.html)). Le dernier firmware publié est **2025120902**, « suitable for any ShowNET-equipped laser system » ([page firmware 2025120902](https://www.laserworld.com/en/download-file-2037-application_shownet_2025120902.html)). La mise à jour se fait avec le **ShowNET Admin Tool (≥1.40), sous Windows uniquement**, suivie d'un power-cycle — une **action de l'utilisateur** (les règles du projet interdisent aux agents de flasher ou de toucher aux DIP/Admin Tool). Il reste **non confirmé publiquement** qu'une unité de 2016 (HW-ID 4) se met à jour proprement jusqu'au Professional Mode, ni quelle est la version minimale qui l'introduit, ni les étapes exactes pour basculer le boîtier en mode *entrée* Art-Net (à ne pas confondre avec la conversion Art-Net→DMX *out*), ni le workflow d'upload des `.ild` sur la carte par le LAN — autant de points à régler avec Laserworld. La limite de fond est claire : **ce n'est pas un flux de points en direct**, mais du déclenchement + modulation de looks pré-rendus ; « disarm » ici signifie **intensité 0 (ch1=0) ET motif 0 (ch2=0)** à chaque tick, et l'arrêt réel reste matériel (interlock/E-stop/clé).

## Ni open-source ni rétro-ingénierie ne pilotent le ShowNET — et ce n'est pas recommandé

Le constat communautaire et le balayage GitHub convergent : **en 2026, aucun dépôt de code public — GitHub, GitLab ou ailleurs — ne pilote le ShowNET**, ni via le SDK officiel ni par rétro-ingénierie du flux de points. Les huit logiciels à sortie ShowNET sont tous fermés et lient le SDK binaire, clé par partenaire, sous NDA. Les applications laser open-source notables (ofxLaser, Libera, laser-dac JS et Rust) **excluent délibérément le ShowNET** et ne visent que des DAC à protocole publié (Ether Dream, Helios, IDN) ([github.com/sebleedelisle/ofxLaser](https://github.com/sebleedelisle/ofxLaser) ; [docs.rs/laser-dac](https://docs.rs/laser-dac) ; [Volst/laser-dac](https://github.com/Volst/laser-dac/)). Le `mimi6060/ilda-laser` de l'utilisateur est le seul projet open-source qui contienne même une amorce de sortie ShowNET — un stub en attente du SDK. **Piège de recherche à écarter** : la quasi-totalité des résultats « ShowNet open source / reverse engineered / OLA » concernent le **« ShowNet » de Strand Lighting (un protocole DMX-sur-IP de scène, sans rapport)**, et non le ShowNET laser de Laserworld ; c'est cette collision de noms qui fait croire à tort que « ShowNET est rétro-ingénieré » ([wiki OpenLighting : Shownet](https://wiki.openlighting.org/index.php/Shownet) ; [OLA API docs](https://docs.openlighting.org/ola/doc/latest/namespaceola_1_1plugin_1_1shownet.html)).

Sur le **chiffrement et la rétro-ingénierie** : plusieurs sources indépendantes s'accordent à dire que le flux live est **« a closed protocol »** gardé par des clés par partenaire, et Laserworld le garde fermé pour éviter que le ShowNET soit « cloned by unscrupulous manufacturers » ([forum Liberation Laser](https://forum.liberationlaser.com/t/are-laserworld-ds-1000-mk4-s-supported/2126)). Le mot « encrypted » est le cadrage « keys/NDA » de Laserworld plus qu'une preuve cryptographique documentée publiquement — mais la conséquence pratique est identique : sans la clé, disséquer la structure ne donne rien d'exploitable. **Aucun projet de clé fuitée ou de cassage du protocole n'a été trouvé** ; c'est reporté comme une absence factuelle, pas comme un encouragement. Utiliser des clés fuitées ou contourner le chiffrement violerait la NDA du SDK et vraisemblablement le droit anti-contournement, et contredirait les règles IP du projet : **cette voie n'est ni recommandée ni légale, et doit être écartée.** Enfin, pour mémoire et sans en faire le sujet, la sagesse communautaire pour un budget serré propose une alternative matérielle légitime : brancher un **DAC ouvert bon marché (Helios) sur l'entrée ILDA standard du projecteur**, piloté par du code ouvert — au prix de ne plus utiliser le boîtier ShowNET pour ce signal ([forum Liberation Laser](https://forum.liberationlaser.com/t/are-laserworld-ds-1000-mk4-s-supported/2126) ; [docs Liberation : DAC compatibles](https://docs.liberationlaser.com/hardware/compatible-lasers-and-controllers-dacs)).

## Conclusion : recommandation priorisée et prochaines actions

Le chemin unique à privilégier est **TouchDesigner Non-Commercial en pont PONK** : c'est gratuit, légal pour un usage non rémunéré, sans NDA, sans nouveau matériel, il garde le ShowNET que l'utilisateur possède déjà, et il transporte le vectoriel sans perte via le PONK que Laser Studio émet déjà. Tout repose sur **une vérification pratique à faire en priorité** — charger le plugin PonkReceiver de MadMapper dans une install TouchDesigner Non-Commercial et confirmer qu'il apparaît dans OP Create sans erreur de licence — en lisant au passage le dossier `Touch Plugin/` du dépôt pour fixer le nom de l'opérateur, le port et le mode (le code de Laser Studio émet en unicast `127.0.0.1:5583`, nom « Laser Studio »). Si ce test échoue, le repli est l'entrée **OSC/UDP native** dans TouchDesigner. En parallèle immédiat et à coût nul, la **voie SD + Art-Net** mérite d'être activée pour avoir une sortie « live-ish » autonome dès maintenant — son seul verrou est une **mise à jour firmware** (2016 → build 2025, via l'Admin Tool Windows, action utilisateur), qu'il faut faire de toute façon pour toute évolution future.

Le SDK officiel reste l'objectif de fond — la seule voie vers un vrai flux de points natif — mais c'est un pari à horizon long : il faut lever trois inconnues auprès de Laserworld, qu'aucune source publique ne résout. Les **questions directes à poser** (par téléphone au siège suisse, +41 71 677 80 80, et à Norbert Stangl) : (1) une adresse d'indépendant belge, voire une adresse privée, satisfait-elle la « legal business address » de la NDA, ou faut-il une société ? (2) le SDK et les clés sont-ils gratuits ? (3) une unité externe de 2016 (HW-ID 4) peut-elle être flashée jusqu'au firmware actuel supportant le Professional Art-Net ? Il faut se présenter dans leurs mots (« publicly available software project », « commercial integration partner »), signaler le formulaire d'inscription cassé, et — seulement si Laserworld confirme qu'une adresse d'entreprise est requise — enregistrer une entreprise individuelle belge (~105–175 €) comme moyen le moins cher de garantir l'acceptation. Open-source et NDA sont compatibles : clés et binaire hors Git derrière la feature `shownet`, le reste sous MIT/GPL, avec un *carve-out* demandé pour que le code publié ne soit pas couvert par la confidentialité.
