## Contexte
Les raccourcis se multiplient (cues, pages, tempo, strobe, inversion, caméra, projet, annuler) et risquent de se chevaucher. Une table unique évite les conflits et permet une aide à l'écran.

## À faire
- Une seule table JS `SHORTCUTS` (code touche via `e.code`, modificateurs, action, libellé français, contexte) ; un seul gestionnaire `keydown`/`keyup` qui la lit. Migrer les raccourcis existants (Échap, Espace, lettres de cues) et ceux des tâches déjà faites.
- Priorité fixe : Échap (noir) avant tout, toujours, même dans un champ texte ; puis Espace (armer) hors champ texte ; puis le reste hors champ texte.
- Test de non-conflit : deux entrées ne peuvent pas avoir la même combinaison dans le même contexte.
- Touche `?` (ou bouton *Raccourcis* dans la barre d'état) : superposition listant tous les raccourcis groupés (*Sécurité*, *Cues et pages*, *Tempo*, *Direct*, *Vue 3D*, *Projet*), avec la touche affichée selon la disposition du clavier quand `navigator.keyboard.getLayoutMap()` est disponible.

## Modèle de données
UI : `SHORTCUTS: Array<{ code, shift, alt, meta, action, label, group, context }>`.

## Interface
Libellés : *Raccourcis*, groupes ci-dessus. Réservés : Échap (noir), Espace (armer), lettres (cues), Entrée (tap, T-150), ⌫ (resync, T-150), Maj tenu (strobe, T-142), `<` tenu (inverser, T-143), F1–F12 et Alt+1…9 (pages, T-272), Alt+Maj+1…6 (caméra, T-278), Cmd+S/O/Z/Maj+Z (projet, T-286/T-285), `?` (aide).

## Critères d'acceptation
- [ ] `?` ouvre la superposition, Échap la ferme ET fait le noir (Échap reste prioritaire)
- [ ] Le test de non-conflit échoue si on ajoute un doublon
- [ ] Aucun raccourci n'est déclenché quand le focus est dans un champ texte, sauf Échap
- [ ] Tous les raccourcis existants marchent comme avant (e2e existants verts)

## Tests
Unitaires JS (via e2e `page.evaluate`) : unicité de la table. e2e : `?`, Échap depuis un champ, une lettre déclenche la cue.

## Notes
Lire les touches par `e.code` pour être indépendant AZERTY/QWERTY. Règles de CLAUDE.md : laser désarmé au démarrage, Échap = blackout instantané, sécurité appliquée en dernier (après calibration), tests en aperçu uniquement (jamais `--device`). Propriété intellectuelle : concepts inspirés de la doc publique Pangolin/Laserworld et des visualiseurs du marché, rien de copié (ni captures d'écran, ni icônes, ni noms d'effets, ni contenus).
