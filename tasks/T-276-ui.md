## Contexte
Pour juger un look, la luminosité relative compte autant que la géométrie : un faisceau fixe est éclatant, une nappe balayée est pâle, trop de faisceaux les rend tous faibles. La brume et le halo donnent la lecture « festival ».

## À faire
- **Énergie conservée** : chaque point reçoit l'alpha `k / N` (N = nombre de points de l'image, k = *Exposition*). Les points répétés (temporisation aux coins de `densify`) s'additionnent naturellement.
- **Nappes** : pour deux points allumés consécutifs, un triangle fin projecteur → impact i → impact i+1, même règle d'alpha ; option *Nappes* activable.
- **Brume** : curseur *Densité* 0–100 % qui module l'alpha ; atténuation `exp(-σ·d)` le long du faisceau ; option *Brume animée* (bruit 3D qui défile lentement, échantillonné par position dans le shader).
- **Lumière de salle** 0–100 % : luminosité de la géométrie de la salle.
- **Impacts** : petit sprite additif là où le faisceau touche une surface.
- **Halo** : faisceaux rendus dans une cible demi-résolution, flou (2–3 niveaux), ajouté à l'image.
- Niveaux de qualité *Basse / Moyenne / Haute* (nappes, halo, brume animée, échelle de rendu 0,5 / 0,75 / 1) ; *Auto* baisse d'un niveau si l'image dépasse 20 ms pendant 2 s.

## Modèle de données
UI : `render = { exposure: 1.0, sheets: true, haze: 0.5, hazeNoise: false, roomLight: 0.1, spots: true, bloom: true, quality: 'auto' }`, enregistré dans `venue.render` quand T-277 existe.

## Interface
Libellés (onglet *Lieu* ou barre sous la vue 3D) : *Exposition*, *Brume : densité*, *Brume animée*, *Lumière de salle*, *Nappes*, *Impacts*, *Halo*, *Qualité* (*Auto*, *Basse*, *Moyenne*, *Haute*).

## Critères d'acceptation
- [x] Un faisceau fixe (1 point répété) est nettement plus lumineux dans la vue 3D qu'un balayage de 200 points de même couleur (mesure de pixel via `readPixels` dans un test)
- [x] Densité de brume à 0 : faisceaux invisibles, seuls les impacts restent
- [x] Qualité *Haute* avec 4 000 points : ≤ 16 ms par image sur Mac M-series (mesure dans le Journal)
- [x] *Auto* passe en *Moyenne* quand on simule une charge (test)

## Tests
Unitaires JS : calcul de l'alpha par point, géométrie des nappes (nombre de triangles = paires allumées). e2e : lecture de pixels au centre d'un faisceau fixe vs nappe.

## Notes
Le rendu est une aide à la conception, pas une mesure photométrique ; l'indiquer dans l'infobulle d'*Exposition*. Règles de CLAUDE.md : laser désarmé au démarrage, Échap = blackout instantané, sécurité appliquée en dernier (après calibration), tests en aperçu uniquement (jamais `--device`). Propriété intellectuelle : concepts inspirés de la doc publique Pangolin/Laserworld et des visualiseurs du marché, rien de copié (ni captures d'écran, ni icônes, ni noms d'effets, ni contenus).
