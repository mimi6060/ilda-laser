## Contexte
En salle, un écran lumineux éblouit l'opérateur et éclaire la régie. Beaucoup de laseristes jouent sur écran tactile, où les petites cibles et les actions au clic droit ne marchent pas.

## À faire
- **Mode nuit** : baisse globale de luminance de l'interface (réglable 40–100 %), plus aucun grand aplat clair ; couleur réservée aux états (rouge = armé/danger, vert = cue active, orange = attente/avertissement). Option *Teinte rouge*.
- Les couleurs passent par les variables CSS existantes (`--bg`, `--panel`, `--accent`, …) ; ajouter les jetons manquants plutôt que des couleurs en dur.
- **Mode tactile** (auto si `pointer: coarse`, forçable) : cibles ≥ 44 px, cases de grille plus hautes, `touch-action: manipulation`, appui long (500 ms) = équivalent du clic droit (remise à zéro d'un contrôle, menu *Apprendre MIDI* de T-203), flash tenu via Pointer Events (pointerdown/pointerup/pointercancel).
- Aucune information uniquement au survol : les infobulles importantes ont un équivalent visible.

## Modèle de données
UI : `prefs = { night: false, nightLevel: 0.6, redTint: false, touch: 'auto'|'on'|'off' }` dans `localStorage` (try/catch).

## Interface
Libellés : *Mode nuit*, *Luminosité de l'interface*, *Teinte rouge*, *Mode tactile*, *Auto*, *Activé*, *Désactivé*.

## Critères d'acceptation
- [ ] Mode nuit à 60 % : la luminance moyenne de la page baisse d'au moins 35 % (capture + mesure)
- [ ] Mode tactile : toutes les cases et boutons de la barre du haut font ≥ 44 px de haut
- [ ] Appui long sur un curseur de *Direct* le remet à sa valeur neutre
- [ ] Un cue en mode flash reste actif tant que le doigt est posé (Pointer Events simulés)

## Tests
e2e : `page.emulate` avec `hasTouch`, appui long, mesures de taille ; capture en mode nuit.

## Notes
Le rouge reste réservé à l'état armé et aux alertes, même en *Teinte rouge* (utiliser alors un contour épais pour l'état armé). Règles de CLAUDE.md : laser désarmé au démarrage, Échap = blackout instantané, sécurité appliquée en dernier (après calibration), tests en aperçu uniquement (jamais `--device`). Propriété intellectuelle : concepts inspirés de la doc publique Pangolin/Laserworld et des visualiseurs du marché, rien de copié (ni captures d'écran, ni icônes, ni noms d'effets, ni contenus).
