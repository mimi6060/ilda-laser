## Contexte
Les visualiseurs haut de gamme (Depence) simulent l'inertie des scanners : une image trop complexe scintille ou arrondit ses coins. Voir ce défaut dans l'aperçu évite des surprises sur site.

## À faire
- Option *Simuler les galvos* : filtre passe-bas du 2e ordre sur la suite de points, paramétré par la vitesse de scan de la sortie (kpps, T-171) et un réglage *Réponse* (ms), avant le calcul des rayons.
- Scintillement : si le temps de tracé d'une image (points / pps) dépasse 1/25 s, moduler la luminosité de l'image dans la vue (et afficher *Image trop longue : scintillement probable*).
- Option *Divergence* (mrad) : épaisseur `w0 + d·tan(div)`, alpha divisé par la largeur.

## Modèle de données
`render.galvo = { enabled: false, response_ms: 0.3 }`, `render.divergence_mrad: 1.0` dans `RenderSettings`.

## Interface
Libellés : *Simuler les galvos*, *Réponse (ms)*, *Divergence (mrad)*, *Image trop longue : scintillement probable*.

## Critères d'acceptation
- [ ] Un carré à 30 kpps a des coins visiblement arrondis avec la simulation et nets sans
- [ ] Une image de 3 000 points à 30 kpps (100 ms) affiche l'avertissement
- [ ] La simulation ne change pas `/api/frame`

## Tests
Unitaires JS : réponse du filtre à un échelon (dépassement, temps de montée).
