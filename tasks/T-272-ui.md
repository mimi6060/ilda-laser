## Contexte
La grille actuelle se remplit automatiquement (cases de 120 px) : les positions changent avec la largeur de la fenêtre, ce qui casse la mémoire des gestes et la correspondance avec l'APC40 (8×5). Les pros utilisent une grille de taille fixe avec pages sur touches F.

## À faire
- Grille de taille fixe réglable : colonnes 4–12, rangées 2–8, défaut **8×5** (40 cases = une page APC40). Les cases s'étirent pour remplir la largeur.
- Une page est une liste de 40 (ou colonnes×rangées) emplacements pouvant être vides ; les pages actuelles (catégories des cues intégrés) deviennent les pages par défaut, remplies dans l'ordre.
- Chaque case affiche : nom, touche clavier (26 premières cases : `azertyuiop` / `qsdfghjklm` / `wxcvbn` lus via `e.code` pour marcher en AZERTY comme en QWERTY), couleur de la cue (bande à gauche), états *active*, *tenue* (flash), *en attente* (lancement quantifié T-159, bordure orange clignotant au temps).
- Onglets de pages avec la touche affichée ; `F1`–`F12` et `Alt+1`…`Alt+9` changent de page (les touches F des Mac demandent souvent `fn`).
- Les cases vides sont grisées, non cliquables.
- Les pages et la taille de grille sont enregistrées (dans le projet T-286 quand il existe, sinon `studio-data/pages.json`).

## Modèle de données
```rust
#[serde(default)]
pub struct CueGrid { pub cols: u8, pub rows: u8, pub pages: Vec<CuePage> } // défaut 8×5
#[serde(default)]
pub struct CuePage { pub name: String, pub slots: Vec<Option<CueRef>> }
pub enum CueRef { Builtin(String /* id preset */), User(String /* id cue utilisateur */) }
```
API : `GET /api/grid`, `POST /api/grid` (taille, pages).

## Interface
Libellés : *Taille de grille*, *Colonnes*, *Rangées*, *Nouvelle page*, *Renommer la page*, *Page vide*. La touche de chaque case est affichée en haut à droite (`kbd`). Glisser-déposer pour réordonner hors *Mode spectacle* (T-283).

## Critères d'acceptation
- [ ] Par défaut 8 colonnes × 5 rangées quelle que soit la largeur de la fenêtre
- [ ] Changer la taille en 6×4 garde les cues dans l'ordre et les enregistre
- [ ] `F2` ou `Alt+2` affiche la page 2 ; les touches lettres déclenchent les cues de la page affichée
- [ ] La touche `a` sur un clavier AZERTY et `q` sur un clavier QWERTY (même `e.code` `KeyQ`) déclenchent la même case
- [ ] Un projet enregistré avant cette tâche (scènes seules) se charge sans erreur

## Tests
Unitaires : (dé)sérialisation de `CueGrid` avec valeurs par défaut, remplissage des pages depuis les catégories. e2e : taille de grille, touches F/Alt, clic sur case vide sans effet.
