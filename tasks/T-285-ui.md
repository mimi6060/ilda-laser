## Contexte
Une modification ratée pendant la préparation (cue écrasée, page réordonnée, correspondance MIDI effacée) doit pouvoir s'annuler. Les consoles d'éclairage ont la touche « Oops » : appui = annuler, maintien = historique.

## À faire
- Pile d'annulation côté serveur sur le projet en mémoire (T-286) : chaque route d'édition enregistre une commande réversible (ou un instantané de la section modifiée), 50 niveaux.
- **Ne sont pas annulables** : déclenchement de cues, maîtres en direct, tempo, armement, noir (ce sont du jeu, pas de l'édition).
- `Cmd+Z` / `Cmd+Maj+Z` (hors champ texte) ; boutons dans la ligne d'état.
- Panneau *Historique* : liste horodatée des 50 dernières modifications ; cliquer une entrée annule jusqu'à elle.
- `POST /api/undo`, `POST /api/redo`, `GET /api/history`.

## Modèle de données
```rust
pub struct EditHistory { undo: Vec<EditEntry>, redo: Vec<EditEntry>, cap: usize /* 50 */ }
pub struct EditEntry { pub label: String, pub at: String, pub section: String, pub before: serde_json::Value, pub after: serde_json::Value }
```

## Interface
Libellés : *Annuler*, *Rétablir*, *Historique*, libellés d'entrées du type *Cue « Éventail » modifiée*, *Page 2 renommée*.

## Critères d'acceptation
- [ ] Supprimer une scène puis Cmd+Z la restaure à l'identique
- [ ] Déclencher une cue n'ajoute rien à l'historique
- [ ] Au-delà de 50 modifications, la plus ancienne est oubliée
- [ ] Une nouvelle modification après une annulation vide la pile *Rétablir*

## Tests
Unitaires Rust : pile, plafond, annuler/rétablir par section. e2e : suppression + Cmd+Z, clic dans *Historique*.

## Notes
Annuler ne doit jamais changer l'état armé ni rétablir une calibration hors des bornes -1..1. En *Mode spectacle* (T-283), annuler une édition est aussi bloqué. Règles de CLAUDE.md : laser désarmé au démarrage, Échap = blackout instantané, sécurité appliquée en dernier (après calibration), tests en aperçu uniquement (jamais `--device`). Propriété intellectuelle : concepts inspirés de la doc publique Pangolin/Laserworld et des visualiseurs du marché, rien de copié (ni captures d'écran, ni icônes, ni noms d'effets, ni contenus).
