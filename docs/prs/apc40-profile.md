# feat/apc40-profile — T-204 default APC40 / APC40 mkII layout

## What / why
Plug in the APC40 mkII (or an original APC40) and it works with no setup:
the clip grid plays the cues of the current page, the scene buttons pick
pages, Stop All is the blackout, the faders and knobs drive the master
modifiers and layers, Tap sets the tempo, Play drives the timeline. This is
our own layout (research §5), written with the control ids that exist today.

- `studio/profiles/apc40-mk2.json`, `studio/profiles/apc40.json`: the two
  built-in profiles (one mapping per line). `shift_key` = note `0x62`,
  `host_mode` 65 (`0x41`), `encoders` declared (`0x2F` Cue Level, mkII
  `0x0D` Tempo; kept in the profile's `extra`). The two files differ only
  where the hardware does:
  - grid: mkII note `0x20 + c − 8·r` on any channel, APC40 note `0x35 + r`
    on channel `c` (slot 0 = top left, row by row, both models);
  - Nudge − / + = mkII `0x64` / `0x65`, APC40 `0x65` / `0x64` (swapped);
  - BPM: mkII Tempo knob (CC `0x0D`, ±0.5, Shift ±0.1); APC40 Shift + Cue
    Level (±0.5);
  - timeline stop: mkII Shift + Play, APC40 Stop (`0x5C`).
- `studio/src/controls.rs`: **one new control id**, `timeline.toggle`
  (« Lecture / pause de la timeline », trigger, external): the APC's single
  Play button needs play-or-pause, and only `timeline.play` / `.pause`
  existed. It goes through `timeline_play`, so it refuses to start under a
  latched e-stop. `docs/controls.md` regenerated by the test.
- `studio/src/midi/engine.rs` (**safety change, small**): while « Armer
  depuis le MIDI » is off (the default), mappings to `transport.arm` are
  skipped when looking up a message, so **Shift + Stop All falls back to
  the plain Stop All = blackout**. Before, Shift + Stop All did nothing at
  all with the option off: a panic press with Shift held would not have
  blacked out. With the option on, Shift + Stop All held 1 s is the T-208
  arm gesture (unchanged).
- `studio/src/index.html`: built-in profiles are labelled « (intégré) » in
  the Profil list (« APC40 mkII — Laser Studio (intégré) »).
- The server-side cue page (`Shared.cue_page`, `page.*` ids, UI tabs in both
  directions) already existed (T-145/T-155): nothing to add.

Not done (no control id yet, left free for T-203 learning): Shift + pad =
flash, Left/Right 40-cue slices (pages never exceed 40 cues today), Track
Select / Device knobs (generator parameters), Pan/Sends/User knob banks,
strobe fader, mirror/invert/freeze toggles, Metronome « cues sur le temps »,
Record, Nudge as BPM ±0.1 (Nudge moves the phase instead, see below), the
« Disposition de l'APC40 » help (T-210's on-screen APC covers it). LED
feedback is T-205. The studio has 8 pages and 4 layers, so Shift + scene
launch covers pages 6–8 and the layer buttons/faders 1–4.

## Disposition par défaut (pour l'utilisateur)

Identique sur l'APC40 mkII et l'APC40 d'origine, sauf mention.

| Matériel | Action | Avec Shift |
|---|---|---|
| Grille 5×8 | joue la cue n de la page affichée (en haut à gauche = 1re, en bas à droite = 40e ; le mode de la cue — flash, solo… — est respecté) | — |
| Scene Launch 1–5 | page 1–5 | Scene Launch 1–3 : page 6–8 |
| Up / Down | page précédente / suivante | — |
| **Stop All Clips** | **blackout** (comme Échap : désarme et verrouille l'arrêt d'urgence ; « Réinitialiser » dans l'interface) | **blackout aussi** ; seulement si « Armer depuis le MIDI » est coché : maintenir 1 s = armer |
| Clip Stop 1–4 | vider le calque 1–4 | n'importe quel Clip Stop : arrêter tous les cues |
| Activator 1–4 | couper / rétablir le calque 1–4 | — |
| Solo 1–4 | solo du calque 1–4 | — |
| Record Arm 2 / 5 / 6 / 7 | couleur change au beat / réagit à la musique / rotation synchro tempo / inverser la rotation (tant que tenu) | — |
| Fader 1 | taille maître | gradateur calque 1 |
| Fader 2 / 3 | taille X / taille Y (0 → 200 %) | gradateur calque 2 / 3 |
| Fader 4 | vitesse d'animation (0 → ×4) | gradateur calque 4 |
| Fader 5 | vitesse de rotation (−360 → +360 °/s, centre = arrêt) | — |
| Fader 6 | libre (stroboscope plus tard) | — |
| Fader 7 | teinte (mode couleur « Teinte ») | — |
| Fader 8 | taille suit les basses (sensibilité audio) | — |
| Master | **luminosité maître** (reprise au passage : aucun saut) | — |
| Crossfader | position X (centre = 0) | — |
| Potards du haut 1–8 | position Y, angle, décalage de palette, vitesse couleur libre, angle X, angle Y, perspective, étalement arc-en-ciel | — |
| Master (bouton) | — | réinitialiser le direct |
| Tap Tempo | tap | recaler sur le 1 |
| Nudge − / + | retarder / avancer la phase | tempo ÷2 / ×2 |
| Tempo (mkII) | BPM ± 0,5 par cran | BPM ± 0,1 par cran |
| Cue Level | position Y fine | APC40 d'origine : BPM ± 0,5 |
| Play | timeline lecture / pause | mkII : arrêt de la timeline |
| Stop (APC40 d'origine) | arrêt de la timeline | — |
| Pédale | tap tempo | — |

Tous les faders et potards absolus sont « à reprise » (pickup) : ils ne
prennent la main qu'une fois passés par la valeur actuelle. Le laser ne
peut jamais être armé depuis l'APC sans cocher l'option de sécurité.
Les contrôles non listés sont libres pour l'apprentissage MIDI (T-203).

## Risks / for the reviewer
1. **Engine safety change** (Shift + Stop All = blackout while arming from
   MIDI is off). It changes the T-208 behaviour that a reviewer approved
   (« Shift + Stop All is not a blackout »), in the safer direction; any
   mapping to the arm control is invisible while the option is off.
2. `timeline.toggle` is a new id (ids are never renamed).
3. Deviations from the task table, all for lack of a control id: see « Not
   done » above. Nudge moves the phase (T-150's `nudge_up/down`) instead of
   BPM ±0.1; Shift + Nudge = ÷2 / ×2.
4. Faders 2/3 drive size X/Y over 0..200 % (no mirror from a fader); fader
   5 rotation ±360 °/s; fader 7 hue only shows in colour mode « Teinte ».
5. On the APC40 mk1 the top knobs and Cue Level are assumed to send on
   channel 0 in mode 0x41 (mappings use any channel, so it doesn't matter).
6. Tap timing in e2e depends on HTTP jitter (±4 ms per interval for ±1
   BPM): taps are scheduled on absolute times and the median interval is
   used; 48/48 on repeat.

### To try on the real APC40 mkII
1. Controller tab: « Profil : APC40 mkII — Laser Studio (intégré) », no red
   error.
2. Top-left pad = first cue of the page shown, bottom-right = 40th.
3. Scene Launch 3 → page 3 in the UI; click a tab in the UI, then a pad.
4. Master fader: move it before it reaches the current brightness — nothing
   happens until it passes the value.
5. Arm with the on-screen button, then Stop All (also with Shift held):
   instant blackout, red e-stop banner.
6. Tap 4 times on Tap Tempo; turn the Tempo knob (±0.5, Shift ±0.1); Nudge
   + / − moves the beat dots forward / back.
7. Faders 1–5, crossfader, top knobs; Shift + faders 1–4 = layer dimmers.

## Review

Reviewed by the architect (integrator). Clean merge (index only); 410
unit + 2 signal tests, e2e 104/104, clippy clean. Both profiles validated
against the control registry; every absolute mapping uses pickup; arming
only via Shift + Stop All and only with the T-208 option on. Accepted the
safety change in the engine: with the option off, an arm mapping is
ignored so Shift + Stop All falls back to a blackout (safer than doing
nothing on a panic press); the T-208 test was updated accordingly.
Verdict: APPROVED
