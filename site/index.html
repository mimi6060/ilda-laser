Laser Studio

Logiciel de show laser : formes, textes, effets et animations au rythme de la musique, avec un aperçu en direct. Gratuit, pour Mac, Windows et Linux.

🍎 macOS

macOS 11 ou plus récent · Mac Apple (M1…M4) et Intel Télécharger pour Mac

🪟 Windows

Windows 10 ou 11 · 64 bits Télécharger pour Windows ou version portable (.zip, sans installation)

🐧 Linux

Ubuntu 22.04+, Debian 12+, Fedora… · 64 bits Télécharger pour Linux ou archive .tar.gz

Installation

🍎 Sur Mac
  1. Ouvre le fichier LaserStudio-macOS.zip téléchargé : il devient Laser Studio.
  2. Glisse Laser Studio dans le dossier Applications.
  3. La première fois, macOS dit que l'app vient d'un développeur non identifié. Fais clic droit › Ouvrir, puis Ouvrir.
    Si ça ne marche pas : Réglages Système › Confidentialité et sécurité, tout en bas Ouvrir quand même.
  4. Si le studio demande le micro, accepte : c'est pour que les effets suivent la musique.
🪟 Sur Windows
  1. Double-clique sur LaserStudio-Windows-Setup.exe : c'est tout. Il s'installe tout seul (sans être administrateur), met une icône sur le Bureau et dans le menu Démarrer, puis lance le studio.
  2. Si Windows affiche « Windows a protégé votre ordinateur » : clique Informations complémentaires, puis Exécuter quand même.
  3. Les fois suivantes, lance Laser Studio depuis le Bureau ou le menu Démarrer. Pour désinstaller : Paramètres › Applications.
  4. Si le pare-feu pose une question, tu peux refuser l'accès réseau public ; autorise le réseau privé seulement si tu pilotes un laser par le réseau.
  5. Une fenêtre noire reste ouverte : c'est le studio. La fermer arrête Laser Studio.
🐧 Sur Linux
  1. Clic droit sur LaserStudio-Linux.AppImage › Propriétés › Permissions › coche Autoriser l'exécution. Ou dans un terminal : 
    chmod +x LaserStudio-Linux.AppImage
  2. Double-clique dessus : une fenêtre de terminal s'ouvre, c'est le studio. La fermer arrête Laser Studio.
  3. Si rien ne se passe, il manque FUSE : sudo apt install libfuse2 (Ubuntu/Debian), ou lance-le avec --appimage-extract-and-run.
  4. Pour un laser Helios en USB, ajoute une règle udev (une seule fois) puis rebranche-le : 
    echo 'SUBSYSTEM=="usb", ATTRS{idVendor}=="1209", ATTRS{idProduct}=="e500", MODE="0666"' | sudo tee /etc/udev/rules.d/99-helios.rules
sudo udevadm control --reload-rules

Premiers pas

  1. Au lancement, Laser Studio s'ouvre dans ton navigateur (adresse http://127.0.0.1:8080 ou voisine). Si rien ne s'ouvre, tape cette adresse toi-même.
  2. Par défaut, c'est le mode Aperçu : rien ne sort vers un laser, tu peux tout essayer sans matériel.
  3. Pour brancher un laser : Réglages › Sorties et projecteurs (Helios USB, Ether Dream, HeliosPRO, LaserCube, MadMapper via PONK…).
  4. Mises à jour automatiques : à chaque démarrage, s'il y a internet, Laser Studio installe tout seul la dernière version puis redémarre. Sans internet, il démarre normalement.
  5. Le laser démarre toujours désarmé. Espace arme le laser, Échap = arrêt d'urgence.

Sécurité

Un laser peut rendre aveugle en une fraction de seconde. Ne vise jamais le public ni les yeux, garde le faisceau au-dessus des têtes ou dans une zone fermée. Les arrêts du logiciel ne suffisent pas : garde toujours à portée de main l'arrêt d'urgence matériel et la clé du projecteur, et teste-les avant chaque show.
