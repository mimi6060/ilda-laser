Un script ajoute un peu de logique aux commandes : si le tempo dépasse 140, passer à la page 3 ; un cue au hasard toutes les quatre mesures. Il lit l'état et envoie des commandes ; il ne peut ni armer le laser, ni toucher à la sécurité, ni lire de fichier, ni accéder au réseau.

  • « + Script » en crée un, « Exemple… » ajoute un de nos exemples, « Supprimer » l'enlève. « Enregistrer » vérifie chaque script : une commande refusée (armer, réinitialiser, sécurité) empêche d'enregistrer.
  • « Déclencheur » : « À la demande » (bouton « Lancer », Cmd+Entrée dans l'éditeur, un pad, une macro, ou « Apprendre MIDI » sur script.<id>.run), « À chaque temps » ou « À chaque mesure » (il faut cocher « Actif »).
  • « Vérifier » signale une erreur avec son numéro de ligne, sans rien lancer. La console montre journal(…) et les erreurs.
  • Deux portes seulement : etat() (tempo, page, cues actifs, contrôles, timeline, audio) et commande("…") (une ligne de la ligne de commande). Plus hasard(), journal("…") et quelques calculs (arrondi, entier, min, max, abs, longueur, texte).
  • Budget : 5 ms, 100 000 opérations et 32 commandes par exécution. Un script qui boucle est arrêté (état arrêté, budget dépassé) et ne repart qu'après une action de votre part. Un script en erreur ne gêne ni les autres ni la lecture.
  • « Arrêter », « Tout arrêter » et l'arrêt d'urgence (Échap) arrêtent les scripts ; leurs déclencheurs attendent « Reprendre les scripts ».
  • Les scripts d'un projet ouvert sont désactivés jusqu'à « Activer les scripts de ce projet » : un projet reçu d'ailleurs ne lance rien tout seul.

Exemple, à chaque mesure :

let e = etat()
if e.tempo.bpm > 140 {
  if e.page != 3 { commande("page 3") }
} else if e.page != 1 {
  commande("page 1")
}

Le mot-clé let s'écrit aussi soit, if / else aussi si / sinon, while aussi tantque, for … in aussi pour … dans. L'arrêt réel du laser reste matériel (interlock, arrêt d'urgence, clé) : voir Sécurité laser.
