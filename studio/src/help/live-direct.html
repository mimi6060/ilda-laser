Le direct modifie ce qui joue, par-dessus les cues : taille, position, rotations, vitesse, couleur, effets.

  • Tous les curseurs : double-clic pour taper une valeur (« 42,5 », « 80 % ») ; Maj + glisser pour un réglage fin ; flèches quand le curseur a le focus ; clic droit ou double-clic sur son nom : valeur neutre. « Tout réinitialiser » remet tout le direct au neutre.
  • Couleur : « Normal » garde celle du cue ; « Fixe », « Palette », « Arc-en-ciel » ou « Chenillard » l'imposent.
  • Effets : « Stroboscope », « Miroir », « Figer (maintenir) », « Noir momentané » (assombrit tant qu'il est tenu, sans désarmer).
  • Le stroboscope reste borné par le limiteur de RÉGLAGES › « Sécurité ». Attention aux personnes photosensibles.
  • Onglets « Maître », « Calque », « Cue » : les mêmes réglages sur tout ce qui sort, sur un calque, ou sur un seul cue en cours. Ils s'enchaînent cue → calque → maître : les tailles se multiplient, les positions et les angles s'additionnent, la luminosité ne fait que baisser.
  • « Enregistrer dans le cue » garde les réglages du cue dans sa case : il les reprend à chaque lancement (« avec le maître » y ajoute ceux du maître). Refusé en mode spectacle.
  • « Lissage » : les curseurs glissent au lieu de sauter ; « Inertie » règle la lenteur.
  • Clic droit sur un réglage : « Apprendre MIDI » pour le relier à un bouton du contrôleur.
  • « Brouillard » (une fois la pompe désignée dans RÉGLAGES › Sortie DMX) : la pompe tourne tant que le bouton ou Alt+B est tenu, au plus la durée max d'un jet ; « Ventilateur » règle le ventilateur. Le brouillard n'est pas le laser : armer et désarmer n'y changent rien, l'arrêt d'urgence le coupe.
