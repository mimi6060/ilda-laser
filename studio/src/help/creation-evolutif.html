Un cue évolutif change dans le temps : des courbes animent ses réglages sur une longueur en temps.

  • « Ajouter une courbe » choisit le réglage à animer ; posez des clés sur la courbe.
  • « Longueur » et le mode de lecture (« Boucle », « Une fois », « Aller-retour ») règlent le déroulé.
  • « Enregistrer » garde le programme dans la case du cue.
