La liste à faire avant chaque show avec une vraie sortie. Tant qu'elle n'est pas terminée, l'armement est refusé.

  • Indiquez l'« Opérateur », cochez chaque élément après l'avoir vraiment vérifié, puis « Liste terminée ».
  • Avec PONK ou un ShowNET, « Arrêt matériel testé (interlock ou arrêt d'urgence du projecteur) » est obligatoire : le boîtier peut garder la dernière image si le flux s'arrête, seul l'arrêt matériel est sûr.
  • « Modifier la liste » pour l'adapter à votre installation ; « Recommencer la liste » pour le show suivant. Une liste terminée est reprise si le studio redémarre dans les 24 h, sauf en balayage du public : recommencez-la si le lieu, le câblage ou le matériel ont changé.

Cocher des cases ne rend pas un show sûr : c'est un aide-mémoire. Voir Sécurité laser.
