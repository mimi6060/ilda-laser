Hershey font data shipped with Laser Studio:
  rowmans.jhf  (Roman simplex)
  rowmand.jhf  (Roman duplex)
Unmodified data files taken from https://github.com/kamalmostafa/hershey-fonts
(directory hershey-fonts/, data files only; the library code of that
repository is not used). Laser Studio converts them to strokes when it
starts. Accented letters are composed by Laser Studio's own code (base
letter + accent), they are not part of the Hershey data.

The use restriction below is quoted verbatim from the original Usenet
distribution notice (hershey-fonts/hershey.txt in the same repository):

			the font data:

				A. V. Hershey while working at the U. S.
				National Bureau of Standards.
			- The format of the Font data in this distribution
				was originally created by
					James Hurt
					Cognition, Inc.
					900 Technology Park Drive
					Billerica, MA 01821
					(mit-eddie!ci-dandelion!hurt)
		2. The font data in this distribution may be converted into
			any other format *EXCEPT* the format distributed by
			the U.S. NTIS (which organization holds the rights
			to the distribution and use of the font data in that
			particular format). Not that anybody would really
			*want* to use their format... each point is described
			in eight bytes as "xxx yyy:", where xxx and yyy are
			the coordinate values as ASCII numbers.
